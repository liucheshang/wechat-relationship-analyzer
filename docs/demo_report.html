08 · 心理学框架补完

把聊天记录放到关系科学的尺子上

裸数字没有意义，必须挂在研究基准上：Gottman 的 5:1、Bids 的 86% / 33%、Gable 的主动建设 30–50%。

Gottman 比率趋势

积极互动 ÷ 消极互动。绿线 5:1 为健康线，红线 1:1 为警戒线。词典近似口径，看相对趋势，非原始交互口径。

四骑士

批评 / 防御 / 蔑视 / 筑墙。已剔除「嗯 / 哦 / 好吧」等单字回应——会计入会把筑墙虚高几十倍。

亲密行为对比

关心问候 / 爱称 / 积极词三项，每千条口径。

连接邀请（Bids）接住率

谁发出邀请发出被接住接住率基准
你 → TA716693.0%健康 86% / 离婚 33%
TA → 你2164179683.0%同上
双向合计2235-83.4%长期高于 70% 是扛得住断联的底层原因

Bids＝一方发出的连接邀请（提问、分享、求关注）。接住＝对方以 ≥4 字的实质内容回应，而非「嗯 / 哦 / 好」。参考基准：健康伴侣约 86%，走向离婚的伴侣约 33%。

好消息回应方式（Gable）

一方分享好事时，对方的四种回应：AC 主动建设（追问细节）/ PC 被动建设（简短肯定）/ AD 主动破坏（泼冷水）/ PD 被动破坏（转移话题）。健康区间：AC 占 30–50%。本项为词典近似口径，非 LLM 抽样判断。

Sternberg 三角

亲密 / 激情 / 承诺三维，均为每千条词典口径，用于双方相对比较，不用于绝对打分。

临界慢化理论：系统接近崩溃前，滚动方差与一阶自相关 AR(1) 会同时升高——恢复变慢，通常比断联本身早几个月出现。本数据（匹配窗口对比）：方差 641.4（断联前 61~120 天）→ 600.4（断联前 60 天）；AR(1) 0.07 → 0.33。只有AR(1) 自相关抬升，另一项没跟上——属于弱信号，不足以单独当作断联预警。

10 · 最终药方

她要改什么，你要改什么，你们要一起改什么

每一条都挂了数字。没有数字支撑的建议，是鸡汤；挂了数字的，才是这一份记录能给出的东西。

TA 需要改的

1. 把「分手」从情绪砝码里拿掉——它出现了 60 次，说多了，真要说的那一次就没人当真了。

2. 蔑视类表达 25 次——Gottman 的结论是讽刺比吵架更能预测分手。

3. 「你怎么不回」这句话你说了 21 次（每千条 1.9）——它在对方耳朵里翻译成的是「你不爱我」，而不是「我在等」。把追问换成具体诉求：「我 10 分钟没等到你，会心慌」。

你需要改的

1. 她连发之后（最长一次一口气 11 条），你有 60 次只回了一两个字；反过来，你连发之后她也有 33 次只回了一两个字。两个方向都高——「用短句关机」是你们共用的模式，区别只在于她是用连发把话说完，你是用短句把话关掉。

2. 你只开启了 36.1% 的对话段（TA 63.9%）。主动开口不是讨好，是告诉对方「我也在等」。

3. 你的中位回复是 8.0 分钟，TA 是 3.8 分钟。快慢本身不判对错，但 88 段冲突里占比最高的导火索是「其他 / 无法归类」——它是全报告里最靠一条规则就能消掉的一项。
