要全量、要更深，用本地版

  1. 下载仓库里的 scripts/analyze.py 和 scripts/report_template.html
  2. 如果记录是 CSV / JSON，先跑 python convert.py 导出文件.json 聊天记录.txt
  3. 跑 python analyze.py 聊天记录.txt 报告.html
  4. 浏览器打开生成的 HTML

纯 Python 标准库，不用装任何依赖，不联网。

GitHub 上的导出工具五花八门，字段名不用管，转换脚本会自动认。
