# WeChat Relationship Analyzer

用心理学指标分析你和一个人的微信聊天记录，输出一份深度报告。

**隐私零泄露**：所有分析都在你自己电脑上跑，聊天记录不上传任何服务器。

![报告首屏](https://liucheshang.github.io/wechat-relationship-analyzer/screenshot.png)

*示例报告首屏（模拟数据）：综合健康分五维拆解 + KPI 总览 + 11 章深度分析。*

## 功能亮点

- **33 个分析维度**：依恋四类、四骑士、Gottman 比率、Bids 接住率、Gable 四分类、Sternberg 三角、临界慢化、事件研究、导火索归类……
- **综合健康分（0~100）**：情绪基调 30% / 冲突与修复 25% / 四骑士 20% / 依恋安全 15% / 连接稳定 10%，阈值全公开可复算
- **日历热力图**：GitHub 贡献图风格，铺满全部日期，断联灰格一目了然
- **发送者自动识别**：真名聊天记录自动统计两人消息量定「我 / TA」，也可 `--me 张三 --her 李四` 手动指定
- **编码兼容**：utf-8 / gbk / gb18030 / big5 自动尝试
- **否定守卫**：「不开心 / 不喜欢 / 别哭了 / 没生气」不再被子串匹配误计成另一面
- **精选情感词典**：在基础词表上按聊天语域扩充约 230 个高频情感词（评估过 HowNet / NTUSD / 清华词表整包导入，因书面语中性词污染被否决）
- **媒体消息对比**：图片 / 语音 / 视频 / 红包 / 转账 / 文件 / 链接 / 动画表情 + 撤回消息、拍一拍统计

## 三种用法

### 方式零：免安装 exe（最省事，不用装 Python）

如果你嫌命令行麻烦，直接用打包好的单文件程序（**图形界面版**）：

1. 到仓库的 **Releases** 页面下载 `聊天记录深度分析器.exe`  
   （如果 Releases 里还没放，就往下走**方式二**自己跑，或者用 `scripts/build_exe.bat` 自己打包）
2. 双击打开是一个深色窗口：**把聊天记录文件拖进窗口**（或点击选择，可多选）
3. 点「开始分析」，进度条和日志实时显示，完成后点「打开报告」
4. 报告生成在聊天记录同目录，双击用浏览器打开即可

- 支持 `.txt` 标准格式；`.csv / .json`（其他工具导出的）拖进去会**自动识别字段并转换**
- 窗口不会用完就退，可以连续分析多份记录
- 把文件直接拖到 exe 图标上 = 载入后自动开始分析

这个 exe **完全离线**：不联网、不调用任何 AI、不上传数据，纯本地数学统计。  
想自己从源码打包，双击 `scripts/build_exe.bat` 就行（需要 Python 带 tkinter，先 `pip install pyinstaller`）。

### 方式一：在线版（推荐新手）

直接打开网页，上传聊天记录txt文件，几秒钟出基础报告。

**在线地址**：<https://liucheshang.github.io/wechat-relationship-analyzer/analyzer.html>

- 不需要装Python，打开浏览器就能用
- 数据量大时自动**均匀采样**（覆盖全时间范围，不是只取开头一万条）
- 数据纯本地处理，不上传

**示例报告**：<https://liucheshang.github.io/wechat-relationship-analyzer/demo_report.html>

> 示例报告里的数据是**脚本随机生成的模拟数据**，不是任何人的真实聊天记录。  
> 想复现它：`python scripts/make_demo.py`（会生成 `examples/demo_chat.txt` 并刷新示例报告）。

### 方式二：本地版（完整分析）

5万条消息也能全量跑，出和示例报告一样深度的结果。

**前提**：装了Python 3.8+（不需要pip install任何东西，纯标准库）

**步骤**：

1. 下载仓库里这几个文件（放同一个文件夹）：
   - `scripts/analyze.py`（必须）
   - `scripts/report_template.html`（必须）
   - `scripts/echarts.min.js`（可选，有了它断网也能看图表；没有则联网时自动走 CDN）
   - `scripts/convert.py`（可选，如果你的导出是 CSV / JSON，用它转成 txt）
2. 准备好你的聊天记录txt文件，格式如下：
   ```
   2025-06-01 05:39 | 我 | 出发没
   2025-06-01 05:41 | TA | 到啦
   2025-06-01 05:42 | 我 | [让我看看]
   ```
   就是 `时间 | 发送者 | 内容`，用竖线`|`分隔。发送者写"我"或"TA"。
3. 打开命令行，跑：
   ```bash
   python analyze.py 聊天记录.txt 报告.html
   ```
4. 用浏览器打开生成的 `报告.html`，完整报告就出来了。

## 报告里有什么

**Hero 总览**：4 个 KPI 卡（总消息数 / TA 主动开启的日子 / 最长断联 / Gottman 比率）+ 一句话判词 + 三纸判词（关系总断 / TA 画像 / 你 画像，每条都挂数字）

**11 个章节**（10 个正文 + 1 个数据附录，从"是谁"到"怎么相处"到"怎么办"）：

| #  | 章节             | 看什么                                                                               |
| -- | -------------- | --------------------------------------------------------------------------------- |
| 01 | 两个人的画像         | 焦虑追问 / 回避疏离 / 情绪要挟 / 安全表达，双向每千条                                                   |
| 02 | 同一句话，两种语言      | 语气词 / 人称代词 / 问句 / 高频词 Top8 / 表情策略                                                 |
| 03 | 谁在推，谁在接        | 会话段开启与收尾 / 回复速度 / 连发与"连发后被堵回"                                                     |
| 04 | 感情波动           | 月度情感净分 / 高低点 Top5 / 深夜温差                                                          |
| 05 | 吵架是怎么结束的       | 冲突段 / 谁先低头 / 中位静默，按关系分期拆开                                                         |
| 06 | 节奏与逐月变化        | 24h 生物钟 / 修复率 / 理性指数 / 批评频率逐月                                                     |
| 07 | 数据会讲故事         | 断联前 30 天逐日回放 / 断裂当天时间轴 / 导火索归类 / 称谓温度计 / 最激烈 7 段冲突复盘                              |
| 08 | 心理学框架补完        | Gottman / 四骑士 / Bids 接住率 / Gable 好消息回应 / Sternberg 三角 / 临界慢化（方差+AR1）/ 事件研究 / 话题聚类 |
| 09 | 谁更爱谁           | 13 项投入度逐项对比，每项带口径和读法                                                              |
| 10 | 最终药方           | TA 改 3 条 / 你改 4 条 / 互相谅解 3 条 / 一起改 3 条，每条挂数字                                      |
| 11 | 附录 · 全量数据与延伸维度 | 断联全清单 Top10 / 原始对比全摊开，只陈列不下判断                                                     |

**统计口径（写进报告页脚）**：

- 相邻消息间隔 > 6 小时切一段对话，"主动"只在段的尺度上谈
- 跨人比较的指标一律做每千条或占比归一化，消息多的一方不会自动赢
- 单字词不做子串匹配（"帮忙"不会命中"忙"）；累/困/忙等状态词不算消极情绪；"嗯/哦/好吧"不算筑墙
- 断联月在所有图上显示为 0 或空白，不会被跳过
- 全部为统计推断，不是心理诊断

## 聊天记录怎么导出

这个工具只负责**分析**，不负责**提取**。提取要你自己在电脑上用别的开源工具做（涉及数据库解密，必须在你的电脑上跑）。

常见的开源提取工具（自行搜索、自行判断是否可信）：

- **WeChatMsg**（LC044）—— 图形界面，导出 CSV / TXT
- **chatlog**（sjzar）—— 命令行，导出 JSON，可开 HTTP 接口
- 其他 "微信聊天记录导出" 类工具

**导出的字段名不用管**，`scripts/convert.py` 会自动认。

### 转成分析器要的格式

分析器只认这种一行一条的纯文本：

```
2025-06-01 05:39 | 我 | 出发没
2025-06-01 05:41 | TA | 到啦
```

导出的是 CSV / JSON 的话，用 `convert.py` 转一下（纯标准库，不用装东西）：

```bash
# 从 JSON 转（会自动按时间排序、只留文本消息）
python convert.py 导出文件.json 聊天记录.txt

# 从 CSV 转
python convert.py 导出文件.csv 聊天记录.txt

# 只保留和某个联系人的聊天
python convert.py 导出文件.csv 聊天记录.txt --contact 小美

# 如果你导出的"自己"字段不是"我"，指定一下
python convert.py 导出文件.json 聊天记录.txt --self-names 我,本人,me
```

脚本会先把认到的字段打印出来给你确认。认不出来它会直说，把文件头几行发出来就能加规则。

**在线版（analyzer.html）可以跳过这一步**——它上传时就自动认字段，CSV / JSON / TXT 都能直接拖进去。

### 数据量决定报告质量

| 消息量     | 能看出什么             |
| ------- | ----------------- |
| < 500 条 | 只能看个大概，别当结论       |
| 几千条     | 能看出语气和习惯差异        |
| 1 万条以上  | 能出逐月趋势、断联期、冲突修复节奏 |
| 5 万条以上  | 全套指标都稳，建议用本地版跑全量  |

## 用 AI 帮你解读

报告里的数字是死的，判断是活的。想再深一层，可以把报告关键段落贴给任何 AI（ChatGPT / Claude / DeepSeek 都行），用这个提示词：

```
你是一个关系沟通顾问。下面是一份用统计指标生成的聊天记录分析报告。
请遵守三条规则：
1. 只基于报告里出现的数字下结论，不要脑补报告没写的细节；
2. 每个结论后面标出你依据的是哪个数字；
3. 报告是统计推断，不是心理诊断——不要给人贴人格标签。

先指出这份报告里最值得警惕的 3 个信号（按严重程度排序），
再针对每一个给出一个本周就能执行的具体动作（要具体到"说什么话"）。

【粘贴报告内容】
```

**注意**：聊天记录是隐私，贴给 AI 之前想清楚。姓名、手机号、地址这类信息先手动删掉。

## 它是怎么算的：纯统计，不依赖 AI

这一点很多人问，所以单独说明：

**整个工具从头到尾没有任何 AI 参与。** 报告里每一个数字、每一句判词，都是固定规则算出来的：

- 代码只用了 Python **标准库**（`sys` / `os` / `json` / `re` / `datetime` / `collections` / `shutil`），**没有任何第三方依赖**，也不需要 `pip install`
- 没有任何网络请求：源码里不含 `requests` / `urllib` / `socket`
- 没有任何大模型接口：不含 `openai` / `deepseek` / `ollama` 之类的调用
- 断网、飞行模式下运行，结果完全一样

**所以你可以：**

| 想做的事          | 行不行                           |
| ------------- | ----------------------------- |
| 断网运行          | ✅ 可以，结果一样                     |
| 换台电脑跑（不装任何东西） | ✅ 用 exe 版                     |
| 审计代码确认没偷传数据   | ✅ 搜一遍关键词就知道，共 4 行 import      |
| 改统计口径         | ✅ 词典和阈值就在 `analyze.py` 顶部，随便改 |
| 用 AI 再解读一遍报告  | ✅ 可选，把报告文本贴给 AI，那是另一件事        |

**唯一的"聪明"来自数学**：Gottman 比率、滚动方差与 AR(1) 自相关、中位数、分位数、事件研究（冲突前后消息量的相对基线变化）——都是教科书里的统计方法，可复现、可验证。
