# 💬 wechat-relationship-analyzer

**微信聊天记录关系分析器 · 看看 TA 到底爱不爱你**

把你和 TA 的微信聊天记录喂给它，它用心理学方法告诉你这段关系怎么样。全本地运行，聊天记录一个字都不上传。

> 中文也能搜到：微信聊天记录分析 / 情侣关系分析 / 聊天记录看感情 / 微信导出分析 / Gottman 比率

## 三个版本，按需选

| | 基础版 | 详细版 | 终极版 |
|---|---|---|---|
| 装什么 | `pip install -r requirements.txt` | + `pip install sentence-transformers scikit-learn` | + 装 Ollama 拉模型 |
| 跑多久 | 几秒钟 | 1-2 分钟 | 5-10 分钟 |
| 依赖大模型 | 否 | 否 | 是（本地 Ollama） |
| 包含关系 | — | = 基础版 + 话题聚类 | = 详细版 + LLM 语义判断 |

### 基础版测什么（规则统计）

纯关键词 + 时间戳数数，几秒钟出结果：

- **谁更主动**：谁先开场、谁发语音、谁打电话
- **回复速度**：双方中位数 + P90 回复延迟
- **Gottman 比率**：积极词÷消极词，月度趋势
- **四骑士**：批评/防御/蔑视/筑墙，双向对比谁更多
- **爱情三角**：亲密感/激情/承诺词频趋势
- **关心次数**：谁问谁吃得好睡得好
- **称呼变化**：11 种昵称双向统计
- **断联检测**：最长多久没说话、空月自动补齐
- **深夜聊天**：谁更爱半夜倾诉
- **消息长度**：谁写得更长、谁更敷衍

### 详细版多测什么（+ 话题聚类）

在基础版之上，AI 把几万条消息自动聚成 10 个话题：

- 你们到底都在聊什么？（工作日常/吃饭/吵架/亲密/未来计划…）
- 谁在主动分享生活，谁在单方面输出情绪
- 哪个话题是你们的雷区

### 终极版多测什么（+ LLM 语义判断）

在详细版之上，本地大模型抽样读句子（默认 200 条，可调）：

- **好事回应率**：TA 分享好事时，你是真开心（AC）、敷衍（PC）、泼冷水（AD）、还是不接话（PD）
- 这是 Gable 2004 研究里最能预测关系满意度的指标
- 词典法会误判，必须让 AI 真正读句子才准
- **并发 + 断点续跑**：中途关了重跑不丢进度
- **抽样机制**：不会真的逐条读几万条（太慢），而是从关键句（吵架/关心/好事）里抽样，结果标注覆盖率

## 懒人方法：让 AI Agent 带你跑完全程

如果你不想自己研究提取工具怎么装，直接用 WorkBuddy / Claude Code 这类 AI Agent 工具，它会自己操作电脑帮你完成。

### 准备工作（一次性，2 分钟）

1. 打开你的 AI Agent 工具
2. 在技能里找到 **GitHub** 技能，启用它
3. 登录你的 GitHub 账号
4. 确认你电脑上装了 Python（命令行输 `python --version`，要有 3.10+）

### 然后把这段提示词复制给它

```
我想分析我和某个人的微信聊天记录，看看我们的关系怎么样。

项目地址：https://github.com/liucheshang/wechat-relationship-analyzer

请你按以下步骤带我完成：

1. 先检查我电脑上有没有装 Python，版本够不够 3.10
2. 把这个项目 clone 到我电脑上
3. 告诉我我电脑上微信的版本号，然后帮我选一个最合适的聊天记录提取工具
   - 你自己上网搜一下最新能用的提取工具，看哪个支持我这个微信版本
   - 推荐几个候选，让我选一个
4. 帮我下载并安装那个提取工具
5. 一步步指导我提取我和某个人的聊天记录
   - 需要扫码/确认的步骤提醒我手动操作
   - 提醒我提取前先完全退出微信
6. 提取完成后，用项目里的 convert_input.py 自动格式转换
7. 跑项目里的 run.py 做分析（先跑基础版）
8. 把生成的统计数据结合你的分析能力，给我写一份完整的关系报告

注意：
- 所有数据只在我本地处理，不要上传到任何云端
- 遇到需要我手动操作的步骤（扫码、点确认），停下来告诉我
```

## 手动方法（不想用 AI Agent）

### 第一步：提取聊天记录（不是本项目做的事）

> ⚠️ **本项目只做分析，不做提取。** 你需要先自己把微信聊天记录导出。

GitHub 上搜「微信聊天记录导出」「WeChatMsg」「chatlog」「WeLive」等关键词，挑一个最近还在更新、支持你微信版本的工具就行。微信版本更新很快，具体哪个工具当前能用，**建议直接问 AI 帮你选**，别照着网上的旧教程硬装。

**提取注意事项：**

- 只能提取**你自己账号**在**你自己电脑**上的记录，提取别人的可能违法
- 提取过程中微信会短暂重启，提前保存好其他工作
- 提取完关掉提取工具再登微信，避免冲突
- **数据质量决定分析质量**：
  - 消息越多越好（建议至少 3 个月、1000 条以上）
  - 文本消息为主，图片/语音/表情只统计数量不分析内容
  - 跨年夜、吵架、纪念日这些关键时段不要缺失
  - 手机上的记录记得先同步到电脑再提取

### 第二步：格式转换（自动）

各提取工具出来的格式不一样，跑一行命令自动转成标准格式：

```bash
python convert_input.py --input 你导出的文件.csv --output messages.json
```

脚本会自动识别常见导出格式（CSV / JSON / JSONL），不用你手动调。

### 第三步：装环境

```bash
pip install -r requirements.txt
```

### 第四步：跑分析

```bash
# 基础版（几秒钟）
python run.py --input messages.json --output ./output/

# 详细版（+ 话题聚类）
python run.py --input messages.json --output ./output/ --with-cluster

# 终极版（+ AI 语义判断）
python run.py --input messages.json --output ./output/ --with-cluster --with-llm
```

### 第五步：让 AI 写报告

把 `output/` 里生成的 JSON 文件，连同下面这个提示词，一起丢给任意 AI：

```
你是资深亲密关系分析师。下面是我和 TA 的微信聊天记录统计数据。
请生成一份报告，包含：
1. 互动模式：谁更主动、回复速度、话题主导权
2. 情感状态：Gottman 比率趋势、情绪波动、最近是热是冷
3. 关系质量：吵架修复方式、四骑士信号、好事回应率
4. 性格画像：TA 是什么性格、我是什么性格、我们配不配
5. 改进建议：TA 该改什么、我该改什么、我们该怎么磨合

要求：结论要有数据支撑，语气直接不啰嗦，用判词式短语总结。
```

## 它用了哪些心理学指标？

| 指标 | 来源 | 大白话 |
|---|---|---|
| Gottman 比率 | John Gottman | 积极词÷消极词，健康关系约 5:1 |
| 四骑士 | Gottman | 批评/防御/蔑视/筑墙，头号离婚预测指标 |
| 爱情三角 | Sternberg | 亲密/激情/承诺三条线 |
| Capitalization | Gable 2004 | TA 说好事你是真开心还是敷衍 |
| 断联检测 | 自研 | 最长多久没说话，空月自动补齐 |

> 注：Gottman 比率这里是「词频比」，不是 Gottman 实验室的「交互行为比」，数值不能跨工具比较，但趋势变化有参考价值。
