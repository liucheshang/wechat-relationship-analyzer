# WeChat Relationship Analyzer

用心理学指标分析你和一个人的微信聊天记录，输出一份深度报告。

**隐私零泄露**：所有分析都在你自己电脑上跑，聊天记录不上传任何服务器。

---

## 两种用法

### 方式一：在线版（推荐新手）

直接打开网页，上传聊天记录txt文件，几秒钟出基础报告。

**在线地址**：https://liucheshang.github.io/wechat-relationship-analyzer/analyzer.html

- 不需要装Python，打开浏览器就能用
- 自动采样前1万条消息分析
- 数据纯本地处理，不上传

**示例报告**：https://liucheshang.github.io/wechat-relationship-analyzer/demo_report.html

---

### 方式二：本地版（完整分析）

5万条消息也能全量跑，出和示例报告一样深度的结果。

**前提**：装了Python 3.8+（不需要pip install任何东西，纯标准库）

**步骤**：

1. 下载仓库里两个文件：
   - `scripts/analyze.py`
   - `scripts/report_template.html`
   （放同一个文件夹里）

2. 准备好你的聊天记录txt文件，格式如下：
   ```
   2024-09-19 22:03 | TA | 出发没宝宝
   2024-09-19 22:03 | TA | 还早
   2024-09-19 22:03 | 我 | [让我看看]
   ```
   就是 `时间 | 发送者 | 内容`，用竖线`|`分隔。发送者写"我"或"TA"。

3. 打开命令行，跑：
   ```bash
   python analyze.py 聊天记录.txt 报告.html
   ```

4. 用浏览器打开生成的 `报告.html`，完整报告就出来了。

## 报告里有什么

- **KPI总览**：总消息数、持续天数、谁主动、Gottman比率、最长断联
- **三纸判词**：关系类型 + 对方画像 + 你的画像
- **10个图表**：
  - 两个人的依恋风格对比
  - 语气词/人称/句式对比
  - 谁主动开场、谁回复快、谁连发
  - 情感趋势逐月变化、高低点Top5
  - 冲突次数、谁先修复、静默时长
  - 24小时聊天生物钟
  - Gottman比率趋势（5:1健康线）
  - 四骑士（批评/防御/蔑视/筑墙）
  - 称谓变化（老公/老婆/宝宝）
- **谁更爱谁**：13个维度逐项对比
- **改进建议**：双方各自需要改什么

## 聊天记录怎么导出

这个工具只负责**分析**，不负责**提取**聊天记录。

你需要先自己用别的工具把微信聊天记录导出成txt格式。常见的开源提取工具：
- 搜GitHub上的 "wechat msg export" 或 "微信聊天记录导出"
- 导出后确认格式是 `时间 | 发送者 | 内容`，不对的话自己改一下

**注意**：聊天记录的数量和质量直接影响报告准确度。几千条以下只能看个大概，几万条才能出可靠趋势。
