# 报告生成 Schema（终极版）

> 本文件是给 AI 的"骨架合同"。
> 你（AI）拿到 `stats.json` 后，**必须**按下面 6 个问题组织报告，
> 每个问题下面只能用对应指标，数字必须来自 JSON，不许编造。

---

## 0. 总原则

- 报告只回答 6 个问题，不多不少。
- 每个数字必须能在 `stats.json` 里找到出处；找不到就写"样本不足"。
- 判词从文末【词库】里选，不许现场编新成语。
- 配色、字体、卡片样式见【视觉规范】。
- 所有数据为统计推断，不是心理诊断；末尾必须有边界声明。

---

## Q1 · TA 是个什么样的人？我是个什么样的人？

只看 4 个维度，每个维度一个数值，AI 按数值查表给判词。

| 维度 | JSON 字段 | 阈值 | 判词 |
|---|---|---|---|
| 情绪反应强度 | `emotion.reactivity_score` (0-1) | >0.6 / <0.3 / 中间 | 情绪明牌者 / 恒温器 / 收放自如 |
| 情绪表达方式 | `emotion.expression_score` (表情+单字占比) | >0.4 / <0.2 / 中间 | 情绪缓冲者 / 直球选手 / 收放型 |
| 理性 vs 感性 | `rationality.ratio` (逻辑词/感受词) | >1.2 / <0.7 / 中间 | 律师型 / 诗人型 / 平衡型 |
| 主动 vs 被动 | `initiative.rate` (主动开场占比) | >0.6 / <0.3 / 中间 | 发动机 / 接盘者 / 平衡型 |

输出形式：两张卡片（TA 一张、你一张），每张 4 个标签 + 一句人话解释。

---

## Q2 · 我们俩是什么配对？

把 Q1 的标签拼起来，从下表查配对名：

| 你的标签 | TA 的标签 | 配对判词 |
|---|---|---|
| 情绪缓冲者 | 情绪明牌者 | 棉花×喇叭 |
| 律师型 | 诗人型 | 律师×诗人 |
| 接盘者 | 发动机 | 追逃型 |
| 恒温器 | 情绪明牌者 | 海岸×潮汐 |
| 直球选手 | 直球选手 | 同频共振 |
| 其他组合 | — | 由 AI 按语义自拟，但要 4 字以内 |

输出形式：一段"关系总断"判词卡，3 行：
- 配对名
- 一句"本是互相吸引的补位，却也是彼此耗竭的循环"式的概括
- 长项 / 死穴各一行

---

## Q3 · 这一年关系怎么走的？

### 3.1 关系阶段
- 字段：`timeline.stage`（脚本已判定：蜜月/权力斗争/稳定/疲惫/复燃）
- 输出：阶段名 + 一句话特征

### 3.2 关键冲突时间线
- 字段：`timeline.conflicts[]`（每条含 date, cause, resolution, aftereffect）
- 输出：时间线表格，每条 3 行

### 3.3 断联检测
- 字段：`silence.longest_days`, `silence.who_broke`
- 输出：一句话"最长寂静 X 天，由你/TA 先打破"

---

## Q4 · 吵架怎么收场？

只看 3 个数：

| 指标 | JSON 字段 | 看出什么 |
|---|---|---|
| 修复率 | `repair.rate_by_period` | 谁更怕失去 |
| 静默时长趋势 | `repair.silence_hours_trend` | 变久=危险，变短=变好 |
| 修复方式 | `repair.post_conflict_volume_ratio` | >1.5 = 刷屏宣泄；<1.2 = 冷静后谈 |

输出：3 张小图 + 一段结论（"你们吵得多了，但吵完好得更快了"式）。

---

## Q5 · 谁更爱谁？

一张表，12 个硬指标全部直接数：

```
消息条数 / 主动开场天数 / 关心次数 /
语音数 / 通话数 / 图片分享数 /
转账次数 / 红包次数 /
「爱你」「想你」「宝宝」「老公/老婆」词频 /
主动提未来次数
```

最后一行给综合判断：**TA 在 N 个维度更用力，你在 M 个维度更稳。**
不许下"谁更爱谁"的结论。

---

## Q6 · 怎么办？

对应 Q1-Q4 的短板，每人 3-4 条动作：

- TA 的短板 → 3 条
- 你的短板 → 3-4 条
- 互相谅解 → 2-3 条

每条必须**对应一个数字**，比如"你主动开场 27% → 提到 40%"，不空喊口号。
