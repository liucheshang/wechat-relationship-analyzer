# 报告数据契约

> 这份文件是**指标字典**：报告里每个数字从哪来、怎么算、怎么看、最容易误读成什么。
>
> 用途：改动 `scripts/analyze.py` 时对照它，别把口径改坏；或者别人拿到你的报告，想知道某个数字到底什么意思。
>
> 配套：提示词见 `prompts/one_click_prompt.md`。

---

## 总原则

1. **每个数字必须带两样东西**：口径（怎么算的）和读法（说明什么）。只有数字没有读法的，不许进报告。
2. **跨人比较一律归一化**（每千条 / 占比）。绝对数只用来描述规模，不用来比较谁更爱谁。
3. **统计推断 ≠ 心理诊断**。判词可以狠，但必须挂着数字，且不能给人格贴死标签。
4. **断联月必须留在时间轴上**（填 `null`，不跳过）。跳过断联就会把故事的主角抹掉。

---

## Hero 区

| 指标 | 口径 | 读法 |
|---|---|---|
| 总消息数 | 清洗后的有效条数 | 只说明数据量，不说明感情 |
| TA 主动开启的日子占比 | 有聊天的天里，第一段会话由 TA 起头 / 总有效天数 | 高 = TA 更常先伸手 |
| 最长断联 | 相邻两条消息时间差的最大值（天） | >14 天是结构性信号，不是小情绪 |
| Gottman 比率 | 积极词命中 / max(1, 消极词命中) | 5:1 健康线，1:1 警戒线 |
| 双方回复中位 | 只算 1 分钟 ~ 1 小时的双向回复，取中位数 | 排除断联污染后的真实响应速度 |
| TA 关心次数 | CARE 词典命中（每千条归一化后比较） | 日常照料密度 |

## 01 两个人的画像

| 指标 | 口径 | 常见误读 |
|---|---|---|
| 焦虑追问 | ANXIOUS 词典命中 / 每千条 | 命中的是**表达方式**，不是依恋类型诊断 |
| 回避疏离 | AVOID 词典命中 / 每千条 | 「我没事 / 随便吧」是回避信号，但可能只是累了 |
| 情绪要挟 | THREAT 词典命中（含「分手/拉黑」） | 出现次数越多，这句话的**威慑力越弱**，不是越严重 |
| 安全表达 | SECURE 词典命中（认错/安抚） | 这是"愿意低头的能力"，高 = 关系有修复弹性 |
| 高频词 Top8 | 过滤停用词与表情占位符，`len>1`，取 Top8 | 只反映语言习惯，不反映在乎程度 |

**红线**：这四个维度是**词典近似**，不是量表。报告里必须标"口径：词典近似"。

## 02 同一句话，两种语言

| 指标 | 口径 | 读法 |
|---|---|---|
| 语气词频次 | 单字语气词单独统计，**不参与情感打分** | 决定同一句话是撒娇还是质问 |
| 人称代词 | 「我 / 你 / 我们」出现次数 | 谁更常用「我」= 更自我中心；「我们」多 = 共同体感强 |
| 问句数 | 含 `？/?` 或疑问词 | 提问 = 愿意把球递出去、愿意等回答 |
| 平均字数 | 有效消息平均字符数 | 长句 = 愿意展开；短句 = 收着 |
| 表情策略 | `[xx]` 标记计数 | 表情是**行为**不是文本情绪，单独计数，不进情感分 |

## 03 谁在推，谁在接

| 指标 | 口径 | 读法 |
|---|---|---|
| 逐月消息量 | 按自然月，**连续月份轴含断联月** | 断联月必须留空可见，不许跳过 |
| 主动开场 | 会话段（间隔>6h 切段）的第一条是谁发的 | 只在段尺度上谈，单条消息不叫"主动" |
| 回复速度 | 间隔 1min–1h 的双向回复取中位数 | 秒回不代表更爱，可能只是刚好在玩手机 |
| 连发 | 同一人连续消息数；最长 / ≥3 条 / ≥5 条次数 | 连发 = 倾泻；短回 = 凝练 |
| **连发后被堵回** | 一方连发 ≥3 条后，另一方只回 1-2 字的次数 | **全报告最刺眼的不对称指标** |

## 04 感情波动

| 指标 | 口径 | 读法 |
|---|---|---|
| 月度情感净分 | (积极命中 − 消极命中) / 当月总条数 | 看趋势不看绝对值 |
| 情绪高低点 | 净分的 Top5 / Bottom5 月份 | 要和当月事件对上才有解释力 |
| 深夜温差 | 23:00–6:00 消息占比，双方对比 | 不设防时段的在场程度 |
| 深夜情绪 | 深夜消息的正/负分布 | 深夜更容易说真话，也更容易说狠话 |

---

## 05 吵架是怎么结束的

| 指标 | 口径 | 读法 |
|---|---|---|
| 冲突段数 | 一段会话里 ≥2 条含冲突词 | 占总会话段比例才有意义 |
| 先低头 | 冲突后下一条消息是谁发的 | 谁低头占比高 = 谁更怕僵着 |
| 修复率 | 先低头次数 / 冲突段数 | **最后一期下滑 = 最新警号**，比历史均值重要 |
| 静默时长 | 冲突末句 → 下一条消息的间隔（小时） | **必须排除跨断联的样本**，否则被 132 天拉飞 |
| 「分手」出现 | THREAT 词典中「分手」命中次数 | 出现越多，效力越弱 |

## 06 节奏、理性与情绪

| 指标 | 口径 | 读法 |
|---|---|---|
| 24h 生物钟 | 按小时统计双方消息量 | 谁更常熬夜陪聊 |
| 理性指数 | RATIONAL 词典命中 / 每千条，逐月 | 高 = 习惯讲道理（有时是回避情绪） |
| 批评频率 | CRITICISM 词典命中 / 每千条，逐月 | 四骑士里最伤人的一个 |
| 修复率逐月 | 每月 先低头次数 / 冲突段数 | 时间序列的最后 1-2 个点单独看 |

## 07 数据会讲故事

| 指标 | 口径 | 读法 |
|---|---|---|
| 断联前 30 天逐日回放 | 断联起点前 30 天的逐日消息量 | 有没有"变少 → 变冷 → 断掉"的曲线 |
| 断裂当天时间轴 | 断联前最后一段对话按小时还原 | 只还原因果链，不判谁对谁错 |
| 导火索归类 | 每个冲突段的**第一条**冲突消息按规则归类 | 归不到的进"其他"，且要报占比 |
| 称谓温度计 | 宝宝/宝儿、老婆/老公、亲爱的，逐月 | 改口的时间点往往对应关系转折 |
| 最激烈 N 段冲突复盘 | 按冲突词密度排序，带双方原话 | 这是报告里最"疼"的部分 |

## 08 关系科学框架

| 指标 | 口径 | 读法 |
|---|---|---|
| Gottman 比率趋势 | 逐月，带 5:1 / 1:1 参考线 | 看它有没有系统性下滑 |
| 四骑士 | 批评 / 防御 / 蔑视 / 筑墙，分人计数 | **蔑视**是离婚最强单一预测因子 |
| Bids 接住率 | 问句后下一条是对方发的 = 接住 | 健康组 86% / 离婚组 33% |
| Gable 好消息回应 | 好消息后对方是积极 / 消极 / 忽视 | 词典近似，标清楚 |
| Sternberg 三角 | 亲密 / 激情 / 承诺 三组词典 | **词典近似**，只能看相对大小 |
| 临界慢化 | 滚动方差 + AR1 同时抬升 | 抬升 = 系统在失去恢复力，是断联的前兆 |
| 事件研究 | 冲突后 ±N 天的消息量相对基线 | 看吵完是"刷屏修复"还是"安静下来" |
| 话题聚类 | 关键词分类（工作/家人/钱/出行…） | **词典近似**，只能看占比结构 |

## 09 谁更用力，谁更稳定

13 项逐项对比，每项必须给：**你的值 / TA 的值 / 口径 / 读法**。

消息条数 · 主动开场 · 关心问候 · 爱称 · 「爱你」· 「想你」· 安全表达 · 先低头 ·
表情使用 · 提问 · 平均字数 · 深夜消息 · Bids 接住率

**最后不许下"谁更爱谁"的结论**，只给：TA 在 N 个维度更用力，你在 M 个维度更稳。

## 10 药方

| 分区 | 条数 | 要求 |
|---|---|---|
| 她需要改的 | N 条 | 每条必须挂一个数字 |
| 你需要改的 | N 条 | 每条必须挂一个数字 |
| 互相需要谅解的 | N 条 | 解释"这不是不合适，是没被看懂" |
| 一起改的 | N 条 | 要能本周执行 |

编号必须从 1 连续到最后一条（历史 bug：出现过 `2. 3.` 没有 `1.`）。

---

## 报告页脚必须有的边界声明

- 相邻消息间隔 > 6 小时切一段对话
- 跨人比较一律归一化
- 单字词不做子串匹配；状态词（累/困/忙）不算消极；「嗯/哦/好吧」不算筑墙
- 断联月在所有图上保留（0 或空白），不跳过
- 全部为统计推断，不是心理诊断
