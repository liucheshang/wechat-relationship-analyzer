## 提示词（从下面这一行开始，整段复制）

你是一名同时懂数据分析和前端的工程师。请按下面的**锁定规格**，用 Python 实现一个本地运行的微信聊天记录分析器：读入一个 txt，输出一份单文件 HTML 深度报告。

### 一、项目底线（最重要，先读这段）

1. **单版本**。不要做"基础版 / 详细版 / 终极版"这种分档，就一套，跑到底。
2. **纯标准库**。不许 `pip install` 任何东西，不许 import 第三方包。只用 Python 自带的 `re / json / math / statistics / datetime / collections / html`。
3. **纯本地**。不联网、不上传、不调用任何大模型（不许 Ollama、不许 API）。全部是规则统计。
4. **模板 + 替换**，不要用 f-string 拼 HTML。见第七节的踩坑记录。
5. 输出**单文件自包含 HTML**：CSS/JS 全内联，双击就能打开。

### 三、输入数据格式

每行一条，竖线分隔：

```
2024-09-19 22:03 | 我 | 出发没宝宝
2024-09-19 22:05 | TA | 到啦
```

- 时间 `YYYY-MM-DD HH:MM`，发送者写 `我` 或 `TA`（也兼容 `me` / `自己`）
- **内容里可能含竖线**，必须用 `parts[2:]` 拼回去，不能用 `split('|')` 取第 3 段就完事
- 输入可能带 BOM、可能是 GBK，要容错
- 清洗要剔除：空内容、纯表情标记（`[图片]` `[表情]` 等）、系统消息

**防误伤红线（不做这几条，指标会虚高几十倍，报告直接失真）：**

1. **长度 ≥ 2 的词才做子串匹配**。单字词（嗯/哦/哈/吧…）只能整体相等或作为语气词单独统计——否则「帮忙」会命中「忙」，「为什么」会命中「什么」。
2. **状态词不算消极情绪**。累、困、忙、饿、加班——这是身体状态，不是对关系不满。
3. **「嗯 / 哦 / 好吧」不算筑墙**。它们是低能量回应，不是冷暴力；塞进 STONEWALL 会把普通人打出高分。
4. **跨人比较的指标一律归一化**（每千条或占比）。谁消息多谁就"赢"，那报告没意义。
5. **单字语气词不参与情感打分**，只单独统计频次。

### 六、计算口径（写清楚，报告里要标出来）

1. **会话分段**：相邻两条间隔 > 6 小时算新会话。"谁主动"只在会话尺度上谈。
2. **回复速度**：只算间隔 1 分钟 ~ 1 小时的双向回复，取中位数（排除断联期，否则平均值没意义）。
3. **连发**：同一人连续发消息计数；同时统计"对方连发 ≥3 条后，这一方只回 1-2 字"的次数（这是最刺眼的不对称指标）。
4. **Gottman 比率** = 积极词命中数 / max(1, 消极词命中数)。5:1 健康，1:1 警戒。
5. **冲突段**：一段会话里 ≥2 条含冲突词算一个冲突段；冲突后对方的第一条消息算"修复"。
6. **连续月份轴**：从第一条到最后一条生成**完整月份列表**（含断联月），断联月填 `null`，ECharts 设 `connectNulls:false`。**不允许跳过断联月**——断联恰恰是故事主体。
7. **最长断联**：相邻两条消息时间差的最大值。
8. **Bids 接住率**：问句后下一条是对方发的，算接住。接住数 / 问句总数。
9. **高频词**：过滤停用词和表情占位符，`len > 1`，取 Top8。
10. **临界慢化**：断联前若干周的滚动方差与一阶自相关（AR1），两者同时抬升 = 系统在失去恢复力。

### 七、踩坑记录（真实踩过的，请直接避开）

1. **不要用 f-string 生成 HTML**。JS 里的 `{}` 会和 f-string 冲突，报
   `SyntaxError: f-string: single '}' is not allowed`。正确做法：
   把模板写成**普通三引号字符串**，里面放 `{{PLACEHOLDER}}` 之类占位符，
   Python 算完数据后逐个 `html.replace(...)`；JS 里的复杂数据用 `json.dumps()` 转成 JSON 字符串再插入。
   **所有替换做完后，一定要断言模板里不再残留 `{{`**，否则用户会看到占位符漏在报告里。
2. **图表数据长度必须和 x 轴一致**，否则整块白图。
3. **数值字段要防 `null`**：断联月没有数据，取数时统一走一个 `gm(month)` 兜底函数返回全 0 对象，别到处裸取字典键（会 KeyError 或 NaN 崩图）。
4. **百分比字符串拼接要转义**：`%` 在 Python 格式化里是特殊字符，拼接时用 `%%` 或干脆避开 `%` 格式化。
5. **模板里不要留多余的跳转链接或空图表**——凡是没数据的图，宁可整块不渲染。

## 附：让 AI 解读已经生成的报告

报告里的数字是死的，判断是活的。把报告关键段落贴给任意 AI，用这段：

```
你是一个关系沟通顾问。下面是一份用统计指标生成的聊天记录分析报告。
请遵守三条规则：
1. 只基于报告里出现的数字下结论，不要脑补报告没写的细节；
2. 每个结论后面标出你依据的是哪个数字；
3. 报告是统计推断，不是心理诊断——不要给人贴人格标签。

先指出这份报告里最值得警惕的 3 个信号（按严重程度排序），
再针对每一个给出一个本周就能执行的具体动作（要具体到"说什么话"）。

【粘贴报告内容】
```

**提醒**：聊天记录是隐私。贴给 AI 之前先把姓名、手机号、地址这类信息删掉。
