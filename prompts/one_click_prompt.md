# 一键生成深度关系报告 · 完整提示词

> 用法：把下面整段（提示词 + sample_stats.json 内容）一起发给任意 AI，
> AI 会生成一份跟心理咨询师复盘同等级别的深度 HTML 报告。

---

## 提示词（直接复制下面全部内容发给 AI）

你是一位资深亲密关系分析师，擅长用聊天记录数据深度解读关系。

下面是我和 TA 的微信聊天记录统计结果（stats.json）。请生成一份**非常详细**的深色风格 HTML 报告，深度要达到心理咨询师复盘的水平，不要省略任何部分。

### 全局设置
- 配色：背景 #0f1115，面板 #1a1d24，边框 #2a2d35，正文 #e9eef4，次要文字 #8a93a6
- 你（self）= 蓝色 #60a5fa
- TA（her）= 粉色 #f778ba
- 强调色 = 紫色 #a78bfa
- 好/积极 = 绿色 #4ade80
- 坏/消极 = 红色 #f87171
- 警告/注意 = 金色 #fbbf24
- 图表用 ECharts（CDN: https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js）
- 单文件自包含 HTML，所有CSS/JS内联，直接保存 .html 可打开
- 左侧固定目录导航（宽220px），右侧内容滚动，目录高亮跟随滚动
- 页面最大宽度 1000px，居中

### 报告结构（每个部分都要写详细，不要省略）

#### 一、总览（一页看完）
- 大标题 + 副标题（时间范围 + 总消息数）
- 4个KPI大卡片：总消息数 / TA主动开场率 / 最长断联 / Gottman比率
- **三纸判词**（八字批语感，要狠要准）：
  - 关系总断：一句话概括这段关系是什么类型
  - TA画像：TA是什么性格
  - 你画像：你是什么性格

#### 二、依恋风格与人格
- **TA的依恋风格**：根据数据判断是焦虑型/回避型/安全型，写依据
- **你的依恋风格**：同上
- **人格特质对比**：外向/内向、理性/感性、主动/被动

#### 三、语言风格对比
- **语气词对比**：双方各爱用什么语气词（嗯/哦/啊/呢/吧）
- **人称与句式**：谁更常用"我"，谁更常用"我们"，谁更常发问句
- **高频词Top**：双方各自最爱说的7个词
- **表情策略**：谁更爱用表情、用什么类型的表情

#### 四、互动模式（谁在推谁在接）
- **对话开启与收尾**：谁更常开场，谁更常结束对话
- **回复速度**：中位数 + P90对比
- **连发模式**：谁更爱连发消息（倾泻型），谁更爱短回复（凝练型）
- **消息长度**：谁写得更长
- **深夜聊天**：谁更爱半夜聊，深夜消息数对比

#### 五、情感趋势（关系在升温还是降温）
- **Gottman比率月度折线**：标出健康线5:1
- **四骑士对比**：批评/防御/蔑视/筑墙，谁的蔑视多
- **爱情三角**：亲密/激情/承诺三条线
- **情绪低点与高点**：标出几个最低和最高的月份
- **深夜与白天的温差**：深夜情绪是不是比白天更消极
- **情绪同步性**：相关系数是正还是负

#### 六、冲突与修复（吵完能不能好）
- **冲突次数与修复率**：吵了几次，和好了几次
- **谁先低头**：14次冲突里你先和好9次
- **平均静默时长**：吵完冷战多久
- **冲突导火索分类**：你们主要因为什么吵
- **核心冲突时间线**：列3-5次最重要的冲突

#### 七、节奏与变化（逐月演化）
- **24小时聊天生物钟**：你们一天中什么时候聊最多
- **一周节奏**：周几最多周几最少
- **理性指数逐月**：谁更理性，怎么变化
- **挑对方问题的频率**：谁更常挑刺
- **开心vs不开心净分逐月**：情绪怎么变化
- **回复速度演化**：关系温度的直接读数

#### 八、关系科学验证
- **Bids for Connection**：TA发小信号你接住了吗
- **Capitalization**：TA分享好事时你怎么回
- **爱的五种语言**：TA主要用哪种方式表达爱
- **权力动态**：这段关系谁说了算

#### 九、让人愣住的细节
- **称谓变化**：什么时候改口的，说明什么
- **关键时刻复盘**：挑1-2个最重要的时刻详细分析
- **Critical Slowing**：断联前有没有预警

#### 十、证据总结
- 用2-3段话总结：数据到底告诉了你什么
- 谁更用力，谁更稳定
- 这段关系最大的风险是什么

#### 十一、改进建议
- **TA该改什么**（3条，每条要有数据支撑）
- **你该改什么**（3条，每条要有数据支撑）
- **互相该怎么磨合**（2条，要具体可执行）

#### 末尾
- 加一行小字：本报告为统计推断，非心理诊断。如有情感困扰请咨询专业人士。

---

### 写作要求
1. 所有数字必须来自下面的JSON，不许编造；没有的字段根据数据合理推断
2. 判词要狠要准，不要温柔废话
3. 每个小节都要有结论，不要只列数据
4. 用中文写，语气直接不啰嗦
5. 图表要好看，颜色按上面的配色
6. 每个章节之间有明显分隔
